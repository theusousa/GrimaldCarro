# Grimaldi Estética Automotiva — Landing page

Página estática (HTML + CSS + JS puro, sem frameworks).

- `index.html` — conteúdo da página
- `styles.css` — estilos, efeitos e responsividade
- `script.js` — revelar ao rolar, header compacto, menu mobile, botão flutuante do WhatsApp
- `assets/logo.jpg` — logo

Para visualizar: abra `index.html` no navegador ou rode `python3 -m http.server` na pasta.

## Antes de publicar, substitua

- `[SEU_NUMERO]` — número do WhatsApp com DDI e DDD (ex.: `5511999999999`)
- `[SEU_INSTAGRAM]`, `[TELEFONE]`, `[PREÇO]`, endereço e horários
- `[FOTO ANTES/DEPOIS 1..3]` — fotos da seção Resultados
